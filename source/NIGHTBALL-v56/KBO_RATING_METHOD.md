# NIGHTBALL KBO 2026：全10球団・300選手の査定方法

## 対象・出典

2026年KBOリーグ公式英語サイトのシーズン個人成績から、KIA、サムスン、LG、斗山、KT、SSG、ロッテ、ハンファ、NC、キウムの**10球団**を収録。各球団16野手・14投手、計300人の**実在選手の成績に基づく独自ゲーム能力**を計算する。

公式の根拠：

- 野手基本成績（AVG、PA、AB、H、2B、3B、HR、TB、SB等）
  https://eng.koreabaseball.com/Stats/BattingByTeams.aspx?codeTeam=HT
- 野手補完成績（BB、SO、OBP、SLG等）
  https://eng.koreabaseball.com/Stats/BattingByTeams02.aspx?codeTeam=HT
- 投手基本成績（ERA、IP、G、SV、HLD、被安打、被本塁打等）
  https://eng.koreabaseball.com/Stats/PitchingByTeams.aspx?codeTeam=HT
- 投手補完成績（BB、SO、ER、WHIP等）
  https://eng.koreabaseball.com/Stats/PitchingByTeams02.aspx?codeTeam=HT

URL末尾のKBO球団コードはHT、SS、LG、OB、KT、SK、LT、HH、NC、WO。公式選手ID（pcode）で基本・補完成績を結合し、出典URLを各選手に保持する。

取得時点：2026年11月19日。ゲーム内では通信せず凍結したデータのみを使う。

- 再現用スクリプト：scripts/build-kbo-2026.py
- 取得済み最小限のシーズン数値・選手ID：data/kbo-season-2026.json
- ゲーム査定：dist/kbo-data.js
- 選定名簿と出典の対応：data/kbo-selection-2026.json

生のページHTMLや公式球団ロゴは再配布しない。チームマークはオリジナルのイニシャル画像。

## 能力換算（CPBL・NPBと同じ系列）

野手・投手の計算はCPBL版の既存ルールと同じ。KBOは別のリーグ母集団で評価するため、平均水準の差は別途調整せず「KBOリーグ内での相対的な能力」を表す。

### 野手

- 打率推定： (H + 120×リーグAVG) / (AB + 120)
- 三振率推定： (SO + 100×リーグSO/PA) / (PA + 100)
- ISO推定： ((TB−H) + 100×リーグISO) / (AB + 100)
- 本塁打率推定： (HR + 100×リーグHR/AB) / (AB + 100)
- 盗塁企図率推定： ((SB+CS) + 80×リーグ盗塁企図率) / (PA + 80)
- 三塁打率推定： (3B + 150×リーグ三塁打率) / (AB + 150)

評価母集団は打数20以上の出場選手を平均に含め、100打席以上の選手でパーセンタイル分布を構築。

- ミート：40 + 55×(0.72×打率順位 + 0.28×低三振率順位)
- パワー：35 + 220×ISO推定 + 650×推定本塁打率
- 走力：38 + 60×(0.75×盗塁企図順位 + 0.25×三塁打率順位) + 盗塁成功率補正
- 守備・肩：守備位置を用いた先験的な基準値（**公式実測ではない**）

### 投手

5イニング以上の公式記録でリーグ平均を算出し、20イニング以上の選手をパーセンタイル参照母集団とする。

防御率・奪三振率・四球率・被本塁打率は、30イニング分のリーグ平均を加えて平滑化。

- 制球：35 + 63×低BB/9順位
- 変化・球威：40 + 57×(0.60×K/9順位 + 0.25×低HR/9順位 + 0.15×低ERA順位)
- スタミナ：26 + 9×(投球回/登板数) + 0.05×投球回（40〜98）
- 球速・球種・球種別速度・先発／救援のロールは**ゲーム用推定値**であり、計測済みの事実ではない

投球回の記録（例：152 2/3）を小数152.2ではなく152.666...イニングとして扱う。

全能力はゲーム内35〜98に収める（球速は別スケール）。

## 絶対に誤認しないでほしい項目

- **出場選手と選手名は公式成績から抽出**。公式の英語表記を使用。韓国語・漢字・カタカナへの自動翻字は行わない。
- **背番号は未確認**のため「—」と表示。作り話の番号は入れない。
- **ポジションは暫定的なゲーム用守備割当**。捕手・内野・外野の個人別守備実績は取得した個人成績の表にない。公式在籍ポジションを実証した情報とは異なる。
- **投打の左右も暫定**。現在のプレイ可能版では未確認選手に仮の右打・右投を設定し、estimatesに明示。実際の左右と一致しない選手がいるため、確認済みデータを得れば優先的に更新すべき。
- 試合での球場は**既存の3D球場を暫定的に使用**。韓国10本拠地の3Dモデルを再現したものではない。
- 公式英語ページの球団別選手表は各カテゴリ20名まで表示される。母集団と球団選出の対象は**各表の表示20名まで**であり、KBOに所属する全支配下選手・全出場選手の完全記録ではない。300名はその中から選んだゲーム用名簿。
- KBO・NPB・CPBLの球団を交えた対戦は可能。ただしリーグ間の強さを実測値で校正したものではない。
- CPBLペナント・APBC・キャリアなど既存の競技モードは変更しない。KBOの専用ペナントはこの版には含まれない。

## 再生成について

取得済みの凍結成績から再生成するだけなら外部通信不要。

1. Pythonで requests、beautifulsoup4、lxml を利用できる環境を用意
2. scripts/build-kbo-2026.py を実行（既定は既存ファクトデータからのオフライン再生成）
3. 再取得が必要な場合に限り、元データファイルを管理者が明示的にアーカイブした後で --capture を実行する

同じ公式データページを毎回繰り返して取得する仕組みにはしていない。
