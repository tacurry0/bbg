# NIGHTBALL 7 — THUMB PITCHING

スマホ縦画面の投打野球ゲーム。静的HTML/JS、Three.js、Canvas、Web Audioで動作します。Three.jsはローカル同梱の0.170.0（MIT）です。

## ペナントモード

6つの架空球団から1球団を選んで操作します。オウルズ（巧打）、フォックス（バランス）、ファルコンズ（機動力）、マリナーズ（制球）、ウルブズ（守備）、コメッツ（長打）の72選手に個別の能力があります。各相手と4試合、ホーム・ビジター各2試合の全20試合。リーグ全体では20節・60試合です。

- 1回制。表・裏とも2アウト満塁で始まり、その後は通常どおり打席が続きます。
- 同点なら回数制限なしで延長。延長も毎回、両チームが2アウト満塁から開始します。走者には直前の打順の3選手を配置し、打順は継続します。
- 後攻の勝ち越しでサヨナラ。先攻の勝利は裏の攻撃終了後に確定します。
- 試合後は同節3試合の結果と順位表を表示。「次の試合へ進む」で次節の対戦画面に移ります。ほか2試合は球団能力を使い、同じ特別ルールで自動計算します。
- 勝率、勝利数、得失点差、総得点の順で順位を決め、すべて同じなら同順位。20試合終了後に最終順位と優勝球団を表示します。
- 日程と全試合結果を閲覧可能。ペナントは専用のlocalStorageに自動保存され、通常対戦の中断データと独立しています。投打操作、投手交代、2倍速、親指操作設定も利用可能です。

## 打順・投手・打者の選択

通常対戦は試合設定から、ペナントは各試合前に「打順・先発を選ぶ」で9人の打順と3人の先発候補を選べます。↑↓での移動、標準・長打・機動力・ミートのプリセットに対応します。ペナントの設定は選んだ球団ごとに保存され、中断試合は開始時の打順・登板状況をそのまま再開します。

ホームラン競争は開始前に6球団・54人から打者を選択できます。打者の能力と左右の打席を表示し、選択した打者で10球に挑戦します。打撃練習の選択とは別に記憶します。

6球団対応時の選手生成で未定義の球団ロゴを参照し、旧2D描画へ切り替わっていた不具合を修正しました。WebGL非対応時も同じ3D選手・球場をCPUで描画します。

## 主な機能

- 3回 / 5回制の対戦（標準は5回）、ホームランダービー、打撃練習、投球練習。
- 右親指で押して動かし、離して打つ直接操作。標準は指の左64px・上80pxに照準を表示。横0〜140px・縦0〜160pxで個別調整可能。
- 打撃中は下の操作パッドとSWINGボタンを非表示にし、球場を広く表示。左下にミート/強振の切り替えだけを置きます。投手操作も球場内でコースを指定し、指を離すと投球。球種は球場内のコンパクトなボタンで選択します。
- ミート / 強振、左親指用の右上照準、縮むタイミングリングと「今、離す！」、音と振動の合図。打撃アシストでは手前の球が少しゆっくりになります。
- 打球後の通常 / 2倍速切り替え。投球の速度には影響しません。物理計算は小さい時間刻みで実行します。
- 6球団の架空の野手54人、投手18人。能力と打順が実際のゲームに反映されます。
- 打順の入れ替え、標準 / 長打 / 機動力の打順プリセット。
- 先発選択、投手交代（再登板不可）、疲労、固有の球種・球速・制球・変化量。
- 通常 / 前進 / 長打警戒の守備位置、投球位置の履歴、試合ログ、選手別打撃成績。
- 3つの球場。広さと追い風が打球に反映されます。
- 中断・再開。対戦の状態をlocalStorageに自動保存します。新しい試合を始めると中断状態を置き換えます。
- 打撃練習の選手・球種選択。記録保存、実績、効果音、対応端末の振動、PWAキャッシュ。

## 能力の効果

ミートは照準の大きさ、パワーは打球初速、走力は塁間速度、守備は反応・捕球範囲、肩は送球速度に影響します。左右の打席も描画と打球方向に反映します。「勝負強い」は得点圏の照準と初速、「長距離砲」は強振時の角度に追加効果があります。ほかの特性名は能力の傾向を示します。

## ファイル

`dist/index.html` / `style.css` / `players.js`（架空選手・球場） / `pennant.js`（6球団・日程・順位・自動進行） / `game.js`（ルール・物理・CPU） / `stadium3d.js`（3Dモデル・球場・カメラ）、`canvas3d.js`（同じモデルのCPU表示）、`renderer.js`（最終互換描画） / `app.js`（入力・UI・保存）。`dist`をHTTPの静的ホストで配信します。PWAはHTTPSまたはlocalhostで利用できます。

守備と走塁は自動です。細かい走者判断、併殺・盗塁・エラー・タッチアップなどは簡略化しています。通常対戦の同点は引き分け、ペナントは延長で決着します。

3Dの丸い選手モデル、立体球場、芝の刈り分け、ヘルメットの光沢、照明、影、観客、打球を追うカメラを実装。WebGLが使えない環境では同じ3DモデルをCanvasで描画します。GPU用の光沢や影はCPU表示と異なります。

`node tests/pennant.cjs` で日程の対戦数・ホーム比率、先攻/後攻の得点処理、延長とサヨナラ、保存/再開、20試合完走と順位集計、通常5回制を確認できます。

`node tests/graphics.mjs` は実際の3Dシーン生成・6球団のユニフォーム描画、指定した打順・先発、全54打者の反映を確認します。ブラウザではスマホ幅で3D描画、打順入替、先発選択、ホームラン競争の打者選択を確認しました。

投球と打撃は同じ親指操作です。画面を押したままコースを指定して、離すと投げる／打つ。指の左上（左手設定では右上）への照準の距離は共通の設定で調整できます。投手交代・作戦・履歴は一時停止メニューから利用できます。

`node tests/thumb-controls.cjs` で離す操作、キャンセル、攻守交代・一時停止をまたぐ操作、複数指と二重投球の防止を確認します。

## バージョン8

走者は単打で一塁、二塁打で二塁、三塁打で三塁に止まります。打球を近くから追うカメラと黄色い落下地点表示、キューブ型スコアと5能力の色付きランク表示を追加。球種は12種に拡張し、技巧派は130km台と遅い変化球、速球派は150km後半と高速変化球を持ちます。6球団には異なる本拠地を割り当て、ウルブズは屋根のあるドームです。重複した芝の面を除去し、地面の奥行きと影の設定を修正しました。

## バージョン9

スコアを球場内左上へ移動し、キューブ上面に一・二・三塁の走者を表示。タイミング・投球案内・ミート結果・落下地点の文字を削除。ミートと強振は左下に縦置き。球種は中央のボールを囲む方向別のボタンと変化量表示に変更し、コース操作と分離。落下地点の円は予測滞空時間に応じて縮み、最初のバウンドまたは捕球で消えます。


## V16 試合ルールと選手サイズ
- 最終回以降の裏、サヨナラ打は決勝走者の進塁までで安打を記録し、1点差で終了。柵越え本塁打は全走者の得点を記録。RBI・投手失点・ペナント得失点差も同じ得点を使用。
- 一塁走者がいて2アウト未満の内野ゴロでは、二塁のカバー到達時間・送球・走者の到達時間から併殺または二塁封殺を判定。二塁→一塁の2回の送球を表示。第3アウトがフォースアウトの場合は得点なし。
- バント選択後、投球中に指を離すと90%で1つ進塁＋打者アウト、5%で進塁なし＋打者アウト、5%で全員セーフの単打。2アウトで打者アウトの場合は得点・進塁なし。送りバントは犠打として打数から除外。
- CPUはカウント別の見送り・追い込み後の対応、打者のミート、球速・変化量・同じ配球の反復で打撃精度が変わる。
- 全選手モデル・影を2倍にし、前景の打者の立ち位置を調整。
- `node tests/rules-v16.cjs` はサヨナラ・本塁打、バントの確率境界、第三アウト、併殺の2送球、封殺、CPUの見送りと三振を確認。


## V17 打席カメラ・手動走塁
- 打撃/投球画面だけカメラを後ろへ引き、打者の立ち位置を左右とも外側へ移動。ホームベースは2.2倍。打球時のカメラ高度/FOVと選手モデルの大きさは維持。
- 試合の投球前に「走塁：自動/手動」で切替。設定画面からも変更でき、選択は保存。既存セーブは自動を既定値として読み込む。
- 手動では「全員」または個別走者を選択し、「進塁・停止・帰塁」で操作。進塁を続けて押すと先の塁を予約。個別選択時は同じ倍率でその走者を追う。
- 打者の一塁進塁、押し出される走者の進塁は自動補助。バントの指定確率と柵越え本塁打の進塁は自動処理を維持。
- 守備側は走者と送球の到達時間を見て自動送球。フォースアウト、タッチアウト、フライ帰塁/タッチアップ、2つのアウトも実際の走者位置で処理。全走者が塁へ着いた後も約2.2秒は追加指示できる。
- 第3アウトがフォース/打者の一塁到達前のアウトなら得点を取り消す。タッチアウトはそれ以前の得点を認め、サヨナラ安打は決勝点で終了。走者・送球・選択状態を含め途中保存/再開に対応。
- `node tests/running-v17.cjs` で144の打球/塁/アウト/操作側の組合せと、追加進塁・停止・帰塁・タッチアップ・第3アウト得点・サヨナラ・本塁打・バント・保存/再開を検証。

## V24: 攻守交代スコア表・自動守備の継続・プレーオフ

攻守が変わるたびにスコア表を表示し、タップするまで次の回は始まりません。自動守備ON/OFFと速度は攻守交代をまたいで保持します。待機中の保存・再開にも対応。

通常シーズン終了後、「プレーオフへ」から2位対3位（2勝先取、最大3試合）、1位対準決勝勝者（4勝先取、最大7試合）を実施。勝ち数の持ち越し・事前の勝ち数アドバンテージはありません。試合は通常ペナントと同じ1回制・各回2アウト満塁・同点延長です。上位球団が準決勝1/3戦、決勝1/2/5/7戦でホーム。自チーム以外の試合は1試合ずつ自動進行できます。シリーズ・途中の操作試合・各試合の成績を保存し、優勝時に終了します。通常シーズンの順位/得失点差とは分離して記録。完全同率のシードは直接対決→総得点→既存球団順で決定します。完走済みの旧ペナントからも続けられます。
