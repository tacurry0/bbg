# NIGHTBALL オンラインコミュニティ v274

## 遊び方
- オンライン対戦 → ルーム。公開ルームを作ると、接続中のプレイヤーが一覧から参加できます。非公開ルームは従来の合言葉と招待リンクのみで参加します。
- フレンド：匿名の端末IDをフレンドコードとして登録。ロビーに接続しているフレンドの状態と公開ルームが分かります。登録は端末に保存する片方向のお気に入り方式です。
- 大会：4人／8人で募集、抽選して対戦表を決定。各カードに一意の合言葉を付与。指定された選手が部屋を作り、相手が参加。双方の終了報告で同じ試合IDとスコアが一致すると進出します。引き分けは再戦、切断では勝敗を確定しません。大会のハンデはゼロです。
- ランキング：初期レート1500、K=32のElo参考値。ハンデなしの公開通常対戦を終了したときのみ更新し、同じ試合IDの再送は重複計上しません。接続中のユーザーの自己申告値を並べます。
- 観戦：公開通常対戦中の部屋を最大4人まで観戦できます。得点、B/S/O、走者、打球・守備の座標を表示する読み取り専用の2D実況です。通常の対戦中継・リプレイの映像そのものではありません。観戦者は試合操作送信経路から隔離します。

## 接続と制約
GitHub Pagesで専用サーバーを必要としないよう、既存のPeerJSに加えてロビー専用のPeerを作成します。固定のロビーIDを取れた端末が一時管理者になり、参加者のハートビートを受けて部屋・大会・参考レートの一覧を配信します。登録は35秒で失効し、管理者が退出した場合は他端末が再選出を試行し、直近の大会情報を引き継ぎます。合言葉での従来対戦はロビーの成功に依存しません。
公式の認証・対戦サーバー・改変防止済みのランキングは提供しません。全員が退出した後の大会永続化やPeerJS接続の可用性、ネットワーク越しの観戦を保証するものではありません。公開時に共有するのは生成された匿名ID、公開ニックネーム、参考戦績、公開ルーム情報です。非公開ルームの合言葉はロビーへ掲載しません。
既存のWebRTC対戦セッションおよびv272リレーの挙動を維持。観戦はホストへの別のPeerJS DataConnectionで約4Hz（最大4接続、キュー混雑時送信省略）に制限し、観戦者の入力を既存のonDataへ渡しません。WebSocket専用ルートの第三者観戦は今回の対象外です。

## 検証

既存のオンライン輸送回帰テスト・更新案内検証も引き続き実行します。
